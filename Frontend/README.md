# Kaarigar Frontend (React.js + Tailwind CSS)

Artisan-focused slow marketplace web application featuring:
- Interactive 3D pottery vase hero section with React Three Fiber
- Bold color blocks & brutalist offset shadows inspired by Topicals
- Framer Motion page transitions, card hover image swap, and slide-up cart buttons
- Live multi-faceted filter sidebar
- Image zoom gallery with lens magnification
- Slide-in cart drawer with free shipping goal progress bar
- Test checkout flow (Razorpay UPI, Stripe Card, NetBanking, COD) with animated confetti confirmation.

## Scripts
```bash
npm install
npm run dev      # Start Vite dev server on port 5173
npm run build    # Build for production
```
